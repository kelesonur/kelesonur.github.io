/ʃ/LING313PHONOLOGY PRACTICE

Session guide

Task: Solve 16 problems in four rounds. Each problem asks for an answer and a justification.

Classroom formats

Teams: 2–4 students sharing a device. Assign a reader, an analyst, and a spokesperson; rotate roles after each round. Teams solve the same problems and compare final scores in class. There is no shared online leaderboard.

Projector: The instructor controls one screen. Allow 45–90 seconds of discussion per problem. Collect teams’ answers and justifications before submitting the class response. The on-screen score belongs to the class as a whole.

Suggested timing: 3 minutes to set up, approximately 6 minutes per round, and 5 minutes for final discussion. There is no enforced timer or speed bonus.

Scoring

Each problem is worth 100 points: 60 for the answer and 40 for the justification. For answers with multiple fields, the 60 points are divided equally. A hint deducts 20 points from that problem’s total; the score cannot fall below zero. Only the first submitted response is scored. Errors do not prevent progress. Maximum total: 1600.

Course scope

Based on W1 handout-a, W1 handout-b, and W2 presentation-a. Instructions and explanations are in English; Turkish words are the linguistic data. The aspiration and [c] analyses follow the model in W2. The activity does not attempt to model every speaker’s pronunciation or all contextual phonetic variation.

Morphology appears only in an optional, unscored discussion based on W1’s introductory examples. Detailed suffix-ordering rules are not assessed.

Progress and access

Progress is saved in this browser only and is not synchronized across devices. A real name or student account is not required. This is a practice activity, not a secure assessment; the answer key is included in the app.
