[Constituent]?
or Impostor?

A class game on constituency tests. Each round highlights a string of words. Teams decide whether it is a real constituent, and then the tests show the answer.

Teams

Game length

How to play

  1. Read the sentence. Each team votes: constituent or impostor.
  2. Run the tests one by one. Before each result appears, ask the class to predict it.
  3. Show the verdict. A correct vote earns 1 point. Rounds marked "double points" earn 2.

Always use at least two tests. One test alone can give a false result (Carnie 2013, p. 100). Press Enter to move to the next step.
