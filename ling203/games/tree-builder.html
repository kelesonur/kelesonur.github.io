How to draw top-down
  1. Start with CP. Every clause is CP > C′ > C + TP.
  2. Then TP > subject DP + T′, and T′ > T + VP.
  3. Expand each node left to right, top to bottom, until every head has a word or Ø.

This tool uses null T: when there is no auxiliary or modal, T is Ø with a tense feature, Ø[+past] or Ø[−past], and the verb keeps the tense ending.
